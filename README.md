# 瑞尔特单通道磁传感器系统

## 项目简介

这是一个基于STM32F103C8微控制器的单通道高精度磁传感器系统，支持MLX90393 3D磁传感器的数据采集、处理和控制。该系统采用单通道设计，每个通道包含一对传感器（实际传感器 + 参考传感器），通过多种先进的算法实现高精度磁场测量。

## 主要特性

### 硬件支持
- **主控芯片**: STM32F103C8 (72MHz Cortex-M3)
- **传感器**: MLX90393 3D磁传感器 (支持单通道配对模式)
- **通信接口**:
  - 硬件I2C (用于传感器通信)
  - 软件I2C (备用)
  - UART串口 (用于命令控制和数据输出)
- **扩展**: 支持TCA9548A I2C多路复用器

### 软件功能
- **传感器管理**: 自动扫描、启动、停止传感器
- **数据处理算法**:
  - 自动标定 (去除环境磁场干扰)
  - 死区过滤 (消除微小噪声)
  - 滑动窗口滤波 (平滑数据)
  - 预测补偿 (基于历史数据)
  - 映射转换 (线性变换)
  - 平滑过渡 (稳定性检测)
  - 尖峰滤波 (异常值过滤)
- **配置管理**: 参数保存到Flash，支持掉电保持
- **串口命令控制**: 完整的命令行接口
- **系统保护**: 独立看门狗 (IWDG)

## 快速开始

### 环境要求
- Keil MDK-ARM (版本5.0或更高)
- STM32F103C8开发板
- MLX90393磁传感器模块
- 串口调试工具 (如PuTTY、SecureCRT)

### 编译和下载
1. 使用Keil MDK打开 `Project.uvprojx`
2. 配置调试器连接到STM32F103C8
3. 编译项目
4. 下载程序到开发板

### 基本使用
1. 上电后系统自动初始化
2. 通过串口连接 (默认115200波特率)
3. 发送命令控制传感器

## 串口命令

系统支持丰富的串口命令，详细命令列表请参考 [`串口命令大全.md`](串口命令大全.md)

### 常用命令
- `ML START` - 启动传感器
- `ML STOP` - 停止传感器
- `ML MERSURE` - 单次测量
- `ML CALIB` - 执行标定
- `ML FLAG` - 查看配置标志
- `ML MAPPING` - 查看映射系数

## 技术规格

### 测量范围
- **磁场范围**: ±50mT (X/Y轴), ±80mT (Z轴)
- **分辨率**: 0.15μT (典型值)
- **精度**: ±0.5% (满量程)

### 系统参数
- **采样率**: 可配置 (默认连续采样)
- **数据输出**: ASCII格式，包含时间戳和校验
- **电源**: 3.3V DC
- **功耗**: < 100mA (正常工作)

## 算法说明

### 数据处理流程
1. **原始数据采集**: 从传感器读取X/Y/Z三轴磁场数据
2. **标定补偿**: 减去环境磁场偏移
3. **死区过滤**: 消除微小噪声干扰
4. **滑动平均**: 平滑短期波动
5. **预测补偿**: 基于历史数据预测和补偿
6. **映射转换**: 线性变换到目标范围
7. **平滑过渡**: 检测稳定性并平滑过渡
8. **尖峰过滤**: 检测和过滤异常值

### 配置标志 (FLAG_RES)
系统使用8位配置标志控制各种功能：

| 位 | 功能 | 描述 |
|----|------|------|
| 0 | 标定使能 | 启用/禁用自动标定 |
| 1 | 死区过滤 | 启用/禁用死区过滤 |
| 2 | 滑动窗口 | 启用/禁用滑动平均滤波 |
| 3 | 预测补偿 | 启用/禁用预测补偿 |
| 4 | 映射使能 | 启用/禁用线性映射 |
| 5 | 平滑过渡 | 启用/禁用平滑过渡 |

## 注意事项

1. **电源稳定性**: 确保3.3V电源稳定，避免电源噪声影响测量精度
2. **环境磁场**: 安装时应远离强磁场干扰源
3. **温度补偿**: 在温度变化较大的环境下使用时需要考虑温度补偿
4. **标定**: 每次更换安装位置或环境后应重新标定
5. **串口波特率**: 默认115200，可通过代码修改
