# FIELD · HTML 上位机界面预览

直接双击 `index.html`，用现代 Edge / Chrome 浏览器打开即可。无需安装依赖、构建、启动服务器或联网，所有样式、图标和脚本都在同一个 HTML 文件内。

## 本版可评估的内容

- 顶部串口设置、模拟标定、CSV 数据保存、自动加载配置和配置表。
- 左侧可拖动旋转、缩放、切换透视 / 俯视的三维响应示意曲面。
- 右侧 XYZ 最近 30 秒实时曲线，鼠标悬停查看数值；支持暂停 / 继续。
- 当前 XYZ 输出、合成幅值、峰峰值、演示采样计数及操作记录。
- 配置表对应固件的六个 FLAG_RES 开关及 XYZ 映射系数，可查看命令预览、恢复默认值、保存本地配置。
- 自适应桌面与窄屏布局，原生对话框、键盘焦点及三维视角方向键操作。

## 范围与数据说明

这是前端设计评估版，**没有连接真实串口，也不会向设备发送命令**。串口设置仅保存在浏览器；标定只演示 10 组样本的采集进度。配置表指固件配置，不操作 Windows 注册表。

初始加载 30 秒的合成演示数据，并以模拟 20 Hz 持续更新。这个频率不是硬件实际采样率。配置的映射系数作用于新的演示数据；滤波开关只生成设备命令预览，不模拟固件算法。历史点保持原值。

单通道数据不能重建空间磁场，因此三维曲面只是以 XYZ 输出驱动的响应示意，不是测量得到的磁场分布。输出使用 a.u.（任意单位）；真实物理单位需在后续接入时结合映射含义确定。

CSV 导出最近最多 12,000 个点（10 分钟），包含模拟经过时间、合成时间戳、XYZ 和 `source=demo` 标记。暂停期间模拟时间冻结；时间戳不代表真实设备时间。刷新后数据和操作记录重置。

自动加载开启时，下次打开恢复本机浏览器的配置；关闭时恢复固件默认参数（FLAG_RES `0x3B`，映射 `0.1 / 0.1 / -0.1`）。浏览器限制本地存储时会显示提示。移动 HTML 文件或更换浏览器可能使用独立的本地存储空间。

## 后续接入位置

当前固件文本输出为 `sensor0:<X>, <Y>, <Z>`。后续可替换脚本中的演示数据生成入口，将解码后的三轴数据传给历史缓存与绘制函数。连接、启动、停止、标定和配置命令需在真实设备上验证后接入。本版保留现有 Python 上位机与固件不变。
