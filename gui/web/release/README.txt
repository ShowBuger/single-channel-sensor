FIELD 发布版 · Windows x64

使用：解压完整压缩包，双击 FIELD.exe。需要 Windows 10/11、.NET Framework 4.8
以及 Microsoft Edge WebView2 Runtime。此机已安装运行环境时可离线使用。
WebView2 Runtime 官方下载：https://developer.microsoft.com/microsoft-edge/webview2/

1. 点击“连接串口”，选择设备端口和波特率（默认 921600）。
2. 使用实时曲线、三维示意图和采集启停功能。
3. 启动标定前，请保持设备空载、静止。
4. “保存数据”或“导出数据 CSV”可保存采样数值。
5. 关闭窗口会释放串口；同一串口不能同时由内部版和发布版使用。

本版保留采集、标定、设备复位、演示、图表和 CSV 数据保存，
不提供配置导入、配置写入、配置模板下载或串口日志导出。
设备参数和映射开关请由内部工具预先配置。

网页资源已封装在程序内，不随包提供 HTML/JavaScript 源文件或源码映射。
应用内不提供开发者工具、查看源代码菜单或浏览器专用快捷键。
封装不能防止专业逆向；程序中不应存放密码或其他保密凭据。

曲面和箭头为单点数据的示意形变，不代表实测空间形貌。
界面单位显示 N，数值含义和精度取决于设备固件及其标定状态。

本程序为独立发布版；内部版的配置、日志导出功能不受影响。
