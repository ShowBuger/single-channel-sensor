# MA03 仅使用 v2（固件 1.3.0）

MA03/H743 构建不再包含 legacy 算法阶段表、历史预测/滑动平均实现及其专用运行状态。MA01/L432 和 MA02/F103 仍保留两档支持。

## 算法链与开关

MA03 只有以下阶段顺序，节点开关仍按配置生效：

```text
S0 有效性校验 → S1 坐标旋转 → S2 零偏校正 → S3 MAD 尖峰抑制
→ S4 增益/时间对齐补偿 → S5 IIR → S6 回差死区
→ S7 独立 Z 整形 → S8 标度映射 → S9 静止归零
```

方向矩阵当前为单位矩阵，尖峰是否开启取决于 bit7；连续模式仍不使用主机观测偏差进行时间外推。配置迁移保持原 flags 和映射系数，因此迁移后不会自动打开所有节点。v2 的 S8 不额外对 Z 取绝对值，Z 整形由 S7 开关控制，和原 legacy 的映射行为有区别。

`algo.profile` 固定为 1，默认配置和 MA03 JSON 模板均使用 v2。手动命令、配置导入及配置验证拒绝 MA03 的 profile=0/legacy。底层流水线即使收到未验证的 profile=0，也只运行 v2。

## 标定保留 300 个有效样本

MA03 的 v2 标定固定收集 **300 个有效传感器对样本**，Welford 在线均值/样本方差，不使用原 legacy 标定实现。名义 100 Hz 时约 3 秒，实际时长取决于设备和重试。

总尝试最多 334 次，要求有效比例至少 90%，最长约 10 秒后退出；未收满或比例不够则失败。`ML STATUS` 的标定元数据记录样本数、尝试数、时长和校验。`algo.calib_ms` 为其他板型 v2 保留，MA03 不再用它决定标定样本数。

## 旧配置与 GUI

- Flash Schema 5/6 先校验原记录，再将 MA03 的旧 profile=0 在 RAM 中迁移为 1；保留其余参数。没有隐式写 Flash。
- 损坏的记录不会通过迁移变为合法配置。Schema 6 布局不变。
- `ML VERSION` 增加 `v2_only` 能力；`ML NODES` 追加 `v2_only=1`。
- Web 节点工作台收到该能力后隐藏 legacy 选项并锁定 v2；MA03 配置导入不接受 legacy，省略 profile 时补入 1。其他板型仍可切换。
- `ML FORMAT legacy|v2` 控制的是串口输出格式，与算法无关；继续兼容现有上位机和硬件测试。选择 legacy 输出格式也不会执行 legacy 算法。

## 验证边界

MA03 ARM 模拟器验证默认档、Schema 5/6 迁移、拒绝 legacy 命令/JSON、强制 v2 执行、全阶段快照和 300 样本标定。浏览器模拟串口验证锁定 v2 后节点开关仍可用。

本轮算法测试 30 项通过、2 项历史 legacy 窗口用例跳过；AK 模拟回归 10 项通过、1 项可选接口跳过；Web 测试 56 项通过，浏览器流程 2 项通过。三板编译成功。H743 普通构建 Flash 74,796 B、RAM 35,032 B；MA03 符号表不含 legacy 算法函数。

legacy 黄金文件及旧合成对比报告作为历史资料保留。MA03 不再运行 legacy 黄金回放；`compare_algo_profiles.py` 在 v2-only 构建上拒绝生成伪比较。需要复现历史对比时使用提交 `2597b35` 及对应构建。

软件修改和构建不代表设备已更新；烧录需单独执行。没有以模拟器结果替代 v2 的实测精度验收。
