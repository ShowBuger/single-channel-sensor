## 传感器控制命令

### ML START - 启动传感器

**功能**: 启动传感器并进行自动标定

**格式**:
```
ML START
```

**返回示例**:
```
Sensor started successfully
Running sensor: 0
```

**说明**:
- 系统启动时已自动调用此命令，无需手动执行
- 启动单个传感器并开始数据采集
- 成功启动后显示运行中的传感器编号
- 如果启动失败，返回 "Failed to start sensors"

---

### ML STOP - 停止传感器

**功能**: 停止运行中的传感器

**格式**:
```
ML STOP
```

**返回示例**:
```
Sensor stopped
```

**说明**:
- 停止数据采集
- 不影响传感器硬件配置
- 可以通过 `ML START` 重新启动
- 如果停止失败，返回 "Failed to stop sensor"

---

### ML MERSURE - 单次测量

**功能**: 执行一次完整的测量周期（启动→采集→停止）

**格式**:
```
ML MERSURE
```

**返回示例**:
```
Sensor started for single measurement
sensor0:1.23, -0.45, 2.67
Single measurement completed
```

**说明**:
- 自动启动传感器
- 获取一次数据
- 自动停止传感器
- 适用于需要单次采样的场景
- 如果启动失败，返回 "Failed to start sensor for measurement"

---

### ML CALIB - 手动标定

**功能**: 对运行中的传感器重新执行标定

**格式**:
```
ML CALIB
```

**返回示例**:
```
Calibration completed
```

**说明**:
- 重新计算零点偏移
- 重新计算标准差
- 标定期间请保持传感器静止
- 标定质量直接影响后续测量精度
- 如果标定失败，返回 "Calibration failed"

## 配置管理命令

### ML FLAG - 查看配置标志

**功能**: 显示当前的 FLAG_RES 配置值

**格式**:
```
ML FLAG
```

**返回示例**:
```
FLAG_RES: 0x3B
```

**FLAG_RES 位定义**:

| Bit | 掩码 | 功能 | 默认 |
|-----|------|------|------|
| 0 | 0x01 | 标定使能 | ON |
| 1 | 0x02 | 死区过滤使能 | ON |
| 2 | 0x04 | 滑动窗口滤波使能 | OFF |
| 3 | 0x08 | 预测补偿使能 | ON |
| 4 | 0x10 | 映射使能 | ON |
| 5 | 0x20 | 平滑过渡使能 | ON |

**默认值**: `0x3B = 0011 1011`

---

### ML CHFLAG - 修改配置标志

**功能**: 修改 FLAG_RES 配置并自动保存到 Flash

**格式**:
```
ML CHFLAG <value>
```

**参数**:
- `value`: 十六进制（0x前缀）或十进制数值，范围 0-255

**示例**:
```
ML CHFLAG 0x1B    # 十六进制
ML CHFLAG 27      # 十进制（等同于 0x1B）
```

**返回示例**:
```
FLAG_RES updated: 0x3B -> 0x1B
Config saved to Flash:
  FLAG_RES = 0x1B
  Mapping: X=0.10, Y=0.10, Z=-0.10
```

**错误处理**:
```
# 值超出范围
> ML CHFLAG 300
Error: Value out of range (0-255)

# 格式错误
> ML CHFLAG abc
Error: Invalid format. Usage: ML CHFLAG <value>
Example: ML CHFLAG 0x1B or ML CHFLAG 27
```

**常用配置**:

| 配置 | 值 | 说明 |
|------|----|----|
| 全部启用 | 0x3F | 开启所有功能 |
| 默认配置 | 0x3B | 推荐配置（无滑动窗口） |
| 仅标定 | 0x01 | 只启用标定补偿 |
| 无过渡 | 0x1B | 关闭平滑过渡 |

## 映射系数命令

### ML MAPPING - 查看映射系数

**功能**: 显示当前的 X/Y/Z 轴映射系数

**格式**:
```
ML MAPPING
```

**返回示例**:
```
Mapping values:
  X: 0.100
  Y: 0.100
  Z: -0.100
```

**说明**:
- X/Y/Z 映射系数用于缩放输出数据
- 输出 = 输入 × 映射系数
- 支持正负浮点数

---

### ML SETMAP - 修改映射系数

**功能**: 修改指定轴的映射系数并自动保存到 Flash

**格式**:
```
ML SETMAP <axis> <value>
```

**参数**:
- `axis`: X, Y, 或 Z（大小写均可）
- `value`: 浮点数，建议范围 -10.0 ~ 10.0

**示例**:
```
ML SETMAP X 0.5     # 设置X轴系数为0.5
ML SETMAP Y 0.8     # 设置Y轴系数为0.8
ML SETMAP Z -0.3    # 设置Z轴系数为-0.3（负值反转）
```

**返回示例**:
```
X_MAPPING_VALUE updated: 0.500
Config saved to Flash:
  FLAG_RES = 0x3B
  Mapping: X=0.50, Y=0.10, Z=-0.10
```

**错误处理**:
```
# 轴参数错误
> ML SETMAP W 0.5
Error: Invalid axis 'W'. Use X, Y, or Z

# 格式错误
> ML SETMAP X
Error: Invalid format. Usage: ML SETMAP <X|Y|Z> <value>
Example: ML SETMAP X 0.5
```

**应用场景**:
- **量程调整**: 将传感器输出缩放到目标范围
- **方向反转**: 使用负值反转轴方向
- **单位换算**: 实现不同测量单位的转换

## 数据采集命令

### 连续数据输出

**说明**: 传感器启动后自动连续输出数据

**格式**: 无需命令，系统启动后自动输出

**输出示例**:
```
sensor0:1.23, -0.45, 2.67
sensor0:1.24, -0.44, 2.68
sensor0:1.23, -0.45, 2.67
...
```

**输出格式**:
```
sensor0:<X>, <Y>, <Z>
```

- `X, Y, Z`: 三轴数据（浮点数，保留2位小数）
- 仅输出单个传感器（sensor0）的数据

**输出频率**: 根据主循环速度自动输出

## 数据处理流程

传感器数据经过以下处理流程（按顺序）：

```
原始数据
  ↓
1. 标定值补偿 (Bit 0)
   减去零点偏移
  ↓
2. 预测补偿 (Bit 3)
   使用参考传感器预测并补偿
  ↓
3. 死区滤波 (Bit 1)
   过滤小于 8×标准差 的噪声
  ↓
4. 尖峰滤波 (Always ON)
   过滤大于 20×标准差 的突变
  ↓
5. 滑动窗口滤波 (Bit 2)
   5点平均平滑
  ↓
6. 映射 (Bit 4)
   乘以映射系数
  ↓
7. 平滑过渡 (Bit 5)
   稳定时平滑归零
  ↓
输出数据
```

## 系统启动流程

### 完整启动序列

```
1. 硬件初始化
   ├─ 系统时钟配置 (72MHz)
   │  ├─ HSE: 8MHz外部晶振
   │  ├─ PLL: HSE/1 × 9 = 72MHz
   │  ├─ SYSCLK: 72MHz
   │  ├─ HCLK: 72MHz (AHB)
   │  ├─ PCLK1: 36MHz (APB1)
   │  ├─ PCLK2: 72MHz (APB2)
   │  └─ LSI: 40kHz (用于IWDG)
   ├─ 硬件I2C初始化
   └─ 串口初始化 (115200)

2. 配置加载
   ├─ 从Flash读取配置
   ├─ FLAG_RES
   └─ 映射系数 (X/Y/Z)

3. 自动启动传感器
   ├─ 扫描端口 (Scan_Ports)
   ├─ 启动传感器 (sensor_start)
   └─ 开始连续数据输出

4. 进入主循环
   ├─ 处理串口命令
   ├─ 获取传感器数据
   └─ 打印处理后的数据
```

**启动信息示例**:
```
Config loaded from Flash:
  FLAG_RES = 0x3B
  Mapping: X=0.10, Y=0.10, Z=-0.10
System_Reset
```

## 配置存储说明

### 掉电存储

所有配置参数自动保存到 Flash（最后一页 0x0800FC00）：

| 参数 | 类型 | 大小 | 默认值 |
|------|------|------|--------|
| FLAG_RES | uint8_t | 1字节 | 0x3B |
| X_MAPPING_VALUE | float | 4字节 | 0.1 |
| Y_MAPPING_VALUE | float | 4字节 | 0.1 |
| Z_MAPPING_VALUE | float | 4字节 | -0.1 |
| 校验和 | uint32_t | 4字节 | 自动计算 |

**特性**:
- 修改后自动保存
- 断电后配置不丢失
- 魔数 + 校验和双重验证
- 数据损坏自动恢复默认值

### Flash 寿命

- **擦写次数**: 约 10,000 次
- **建议**: 避免频繁修改配置
- **正常使用**: Flash 寿命充足

## 技术参数

### 通信参数

- **波特率**: 115200
- **数据位**: 8
- **停止位**: 1
- **校验位**: 无
- **流控**: 无

### 系统时钟

- **HSE**: 8MHz 外部晶振
- **PLL**: HSE/1 × 9 = 72MHz
- **SYSCLK**: 72MHz
- **HCLK**: 72MHz (AHB)
- **PCLK1**: 36MHz (APB1, 最大36MHz)
- **PCLK2**: 72MHz (APB2)
- **LSI**: 40kHz (用于IWDG)

### 测量参数

- **传感器数量**: 1个
- **采样间隔**: 由主循环速度决定
- **标定采样**: 10次
- **输出格式**: `sensor0:<X>, <Y>, <Z>`

### 滤波参数

| 滤波器 | 阈值 | 说明 |
|--------|------|------|
| 死区滤波 | 8×σ | 可调 (DEAD_VALUE) |
| 尖峰滤波 | 20×σ | 可调 (SPIKE_FILTER_THRESHOLD_MULTIPLIER) |
| 滑动窗口 | 5点 | 固定 (SLIDING_WINDOW_SIZE) |
| 平滑过渡 | 3×σ | 稳定性检测 |

### A. FLAG_RES 配置示例

**关闭所有滤波，仅标定**:
```
ML CHFLAG 0x01
```

**开启标定和死区滤波**:
```
ML CHFLAG 0x03
```

**开启所有功能**:
```
ML CHFLAG 0x3F
```

### B. 映射系数应用

**缩小量程到一半**:
```
ML SETMAP X 0.5
ML SETMAP Y 0.5
ML SETMAP Z 0.5
```

**反转Z轴**:
```
ML SETMAP Z -0.1
```

**放大10倍**:
```
ML SETMAP X 1.0
ML SETMAP Y 1.0
ML SETMAP Z 1.0
```

### C. 常见问题

**Q: 为什么系统启动后自动开始输出数据？**

A: 系统在main函数中自动执行了 `Scan_Ports()` 和 `sensor_start()`，无需手动发送命令即可开始数据采集。

**Q: 如何恢复出厂设置？**

A: 执行以下命令：
```
ML CHFLAG 0x3B
ML SETMAP X 0.1
ML SETMAP Y 0.1
ML SETMAP Z -0.1
```

**Q: 配置修改后需要重启吗？**

A: 不需要。配置修改立即生效，并自动保存到Flash。
